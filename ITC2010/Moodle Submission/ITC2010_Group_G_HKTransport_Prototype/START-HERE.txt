RUN THE WEB SOURCE LOCALLY
Extract the ZIP. In this folder, run:
    python3 -m http.server 8642 --directory web
Open http://localhost:8642/ in a browser. The local planner uses online transit
data and free map and search services. The live website provides the hosted AI
assistant and Google integrations when available.
