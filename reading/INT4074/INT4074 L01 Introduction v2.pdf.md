Course Synopsis
• Mobile digital devices have become popular nowadays. It can undoubtedly provide an 
excellent educational platform for information and communication technology. This course 
introduces students to important concepts and aspects in mobile application development. 
It aims to equip students with the basic knowledge and skills to develop mobile 
applications. It also offers opportunities for students to examine the use of information and 
communication technology to promote IT education and teaching of sciences, technology, 
engineering, and mathematics education. Through hands-on practical activities, students 
will be able to apply mobile platform programming skills in their own mobile application 
development to promote playful teaching and learning environments.

Overview
• A mobile operating system is a type of 
operating system which is specially designed 
for mobiles, tablets, smartwatches, etc.
• An operating system (OS) is a program that 
acts as an interface between the system 
hardware and the user. 
• Moreover, it handles all the interactions 
between the software and the hardware.

## 第 24 页

4 The Architecture of Mobile OS
23
Components of a Mobile Operating System
• Kernel: The core part of the operating system that interacts with the 
hardware. For instance, Linus is the kernel for Android.
• Process Execution: Manages the execution of processes.
• Interrupt: Handles interruptions and requests from software and hardware.
• Memory Management: Manages the allocation and deallocation of memory.
• Multitasking: Allows multiple processes to run simultaneously.
• Security: Ensures the safety of the system and data.
• User Interface: Provides an interface for users to interact with the system.
