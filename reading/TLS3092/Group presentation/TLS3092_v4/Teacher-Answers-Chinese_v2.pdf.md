課前複習小測 · Lesson 1 HTML
答案：1 A（h1／p）；2 B（src 是來源、alt 是文字替代）；3 C（href="#projects" 配對 id）；4 B（標題後、p 前補
</h1>）。這是第一課的複習，不考 CSS。首五分鐘獨立作答，5–8 分鐘按錯題重溫及補測草稿。
規則、預測與除錯
h1 是選擇器；color 是屬性；#17634b 是值。段落最終為 #17634b，因同條件及同選擇器後出的宣告覆蓋前者。修
正：color 後加入冒號，色碼後加入分號。
h1 { color: #17634b; font-size: 28px; }
section { padding: 20px; margin-top: 24px;
  border: 1px solid #c7d6ce; }
文字至邊框的內側為 padding；邊框外為 margin。CSS 有效值及完整宣告要在瀏覽器測試。
CSS 課後自測（選做）
只在完成 CSS 活動後選做：1 選擇器；2 padding；3 後出現的一條（來源、重要性、層和優先度相同時）；4 足夠
對比、行距、底線。
