General Information
Subject
Information and Communication Technology (ICT)
Topic
Internet and Its Applications – How Data Travels Across a Network
Grade Level
Secondary 4 (S4)
Duration
70 minutes
Learning Objectives
By the end of the lesson, students should be able to:
1.
Tell what the switch and the router do in the network shown in class.
2.
Use arrows on a network diagram to show and explain the path from a client to a server.
3.
Use the simulator to check a predicted path and point out where a missing link would stop communication.
Lesson Plan
Time
Student Activity
Purpose
Teacher Activity
Resources
0–8 min
Introduction
Think back to the devices covered before class. Tell a partner what you think happens between clicking a link and seeing the page.
Find out what the class already knows about where a web request goes.
Put this question on the first slide. “When you click a link, where does your computer send the request?” Take two or three answers and pick up any mention of a switch or router.
PowerPoint, network diagram
8–18 min
Understanding Network Devices
Point to the client, server, switch and router on the school network diagram. Explain to a partner what each one does.
Distinguish the devices that send or answer a request from the ones that forward it.
Start with a computer in the school lab. Show its link to the switch and use the router to explain how traffic can leave the local network. Ask the class to point out the server.
PowerPoint, network diagram
18–28 min
Simulation Demonstration
Follow the connections on the projected screen. Point out the first device the client is connected to, then name the next device on the path.
Show how to read the connections in the simulator before groups start Part A.
Open the client-to-server example in the simulator. Point to each link in order. Pause at the switch. Ask where the request would go next. Trace the rest of the path with the class.
Network simulation tool, projector
28–45 min
Group Activity 1: Exploring Network Connections
In groups of three or four, sketch the path on Part A first. Use the simulator to check which devices are connected. If a link in the sketch is wrong, correct it and explain the change to the group.
See whether students can use the layout to justify the arrows they draw.
Give each group the starting arrangement. While groups work, look at their sketches and ask them to point to the link that supports each arrow. Give a hint if a group gets stuck.
Network simulation tool, Worksheet Part A
45–56 min
Group Activity 2: Solving a Connection Problem
Part B shows a diagram with one connection missing. Mark the gap, explain why the client cannot reach the server along that path, and draw the link you would restore.
Check whether students can locate a fault and propose a repair that fits the diagram.
Show the fault diagram. If a group is unsure where to look, ask them to start at the client and trace the path one link at a time.
Network diagram, Worksheet Part B
56–64 min
Group Sharing and Discussion
Two or three groups show where the path stopped and which link they would restore. Everyone else checks their own Part B diagram during the explanation.
Use the diagrams to see which explanations account for the failed connection.
Ask each presenting group to point to the broken part of the route. Clear up any mix-up between a missing link and a problem with a device.
PowerPoint, student worksheets
64–70 min
Summary and Assessment
Work alone on the exit ticket. In your own words, say what the router does and give one reason the client might fail to reach the server.
Check what each student can explain after the group tasks.
Recap the route on the diagram, then hand out and collect the exit tickets. Point students to the homework in Google Classroom.
Exit ticket, Google Classroom
Remarks
Catering for Learner Differences
Give students who need a starting point a partly labelled diagram. Ask them to find the client first and trace its first link. Groups that finish early can mark a different break on the diagram and explain where the path would stop.
Assessment
During the lesson, check the answers students give aloud and the paths they draw in Parts A and B. On each exit ticket, check that the student explains the router’s role and gives a plausible cause of a failed connection.
Homework
Draw a small network linking a client to a server. Label the devices and say what each one does. Mark one place where the connection might fail and show what you would do to fix it.
