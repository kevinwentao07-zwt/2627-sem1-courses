Inside the Internet   /   1
Network Devices and TCP IP
Core teaching
Two 70-minute double lessons introduce device functions and paths, then TCP/IP transmission. Lesson 1 uses 
Foundation Notes, the Hardware Reference and Worksheet Q1–Q3. Lesson 2 uses TCP/IP Notes, Q4–Q5 and 
Scenario B. Each learner writes their own answers while sharing a computer.
Continuation
The unit continues beyond the core where necessary. Resume unfinished essential activities. For confusion about 
devices or paths, use Follow-up A and Progress Check page 1. For TCP/IP difficulties, use Follow-up B and page 
2. Select or repeat the relevant support; the suggested 20- and 25-minute blocks do not fix the length of the unit.
Application and checking
When the main explanations are secure, use Follow-up C: Scenario A and the separate 12-mark consolidation. A 
new individual question in a later lesson checks whether the learner can explain the idea without notes. Keep the 
core /24 and consolidation /12 separate. Progress Check is unmarked.
Presentation
This presentation pack contains one 25-minute speech for the group. It addresses teachers and uses one brief AP 
demonstration on slide 19. Follow the lecturer’s schedule for questions.
Using the pack
Teacher/English contains the plan, classroom guidance, answer key, slides and presentation script. 
Students/English and Students/Traditional_Chinese contain separate print versions. Presenters/A–E contains each 
member’s script and handover cues. All presenters use the shared Group_Presentation_EN deck. Check the live 
classroom address before use and keep the offline HTML and backup images ready.
