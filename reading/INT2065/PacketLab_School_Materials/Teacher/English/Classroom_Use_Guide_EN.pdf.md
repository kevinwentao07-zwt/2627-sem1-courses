Setup fallback and finishing routine
Before class
Set the live resource to the class language, load the working reference scenarios and test them on the actual 
classroom computer. Open the offline HTML and backup images locally. Print the language version used by the 
class. Hold Worksheet page 4 separately. Check that a mouse, labels and projector view are usable.
If a baseline fails
Check the prepared reference once. If it takes more than two minutes to restore, use the offline or printed 
equivalent. Keep the stated conditions visible and record the actual observed outcome. Do not treat a different 
fault as the answer to the planned test.
Student roles
One learner operates and the other records, then they swap. Both keep their own responses. Pause the class when 
modelling a stage. Use a stable view and a static alternative where needed.

After class
Keep guided and individual evidence distinct. Check Q5 explanations and revisions by concept. Use Progress 
Check and Follow-up A/B/C after reviewing core evidence. Further teaching may use later lessons or parts of 
them. The separate /12 task follows relevant teaching and remains separate from /24.
Subsequent teaching and flexible pacing
Use the Lesson Plan follow-up sections to select support after either core double lesson. The classroom deck 
illustrates the core and relevant modelling stages; it does not set the length of the unit. Resume essential 
unfinished teaching before treating a task as complete.
Device or path gap. Resources and action: Follow-up A; Foundation Notes, Hardware Reference and local/AP 
path view  Independent check: Progress Check page 1 Task 3
TCP/IP gap. Resources and action: Follow-up B; TCPIP Notes and pause or printed parts  Independent check: 
Progress Check page 2 Task 5
Secure core explanations. Resources and action: Follow-up C; Scenario A and separately scored /12 
consolidation  Independent check: Later fresh route or missing-part explanation
When supporting a small group, assign the remaining learners application with stated written conditions. If a 
misconception is widespread, plan a whole-class model in the next period. Record actual time, help given and task 
completion. Keep the teacher answer sheet hidden for each independent recheck.
