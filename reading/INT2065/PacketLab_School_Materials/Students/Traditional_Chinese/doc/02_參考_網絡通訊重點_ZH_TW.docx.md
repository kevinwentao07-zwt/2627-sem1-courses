網絡通訊重點
網絡、範圍與分工
網絡  
讓裝置互相通訊，並共享檔案、打印機等資源。
LAN／WAN  
區域網絡（LAN）覆蓋較小範圍，例如學校電腦室。廣域網絡（WAN）覆蓋較廣，可連接不同地點的網絡。
用戶端／伺服器  
用戶端請求服務，伺服器提供服務。例如瀏覽器請求網頁，網頁伺服器傳回網頁資料。
五種設備的作用
網絡介面卡（NIC）  
讓裝置接入網絡。有線介面使用 Ethernet，無線介面使用 Wi-Fi。
交換器（Switch）  
連接同一 LAN 的裝置，將資料轉送到適當的連接埠。
路由器（Router）  
連接不同網絡，按目的地 IP 地址轉送封包。
無線接入點（AP）  
讓無線裝置透過 Wi-Fi 接入有線 LAN。
數據機（Modem）  
調變及解調訊號，使資料能經接入線路傳送。撥號數據機使用模擬電話訊號。
追蹤路徑與判斷故障
同一 LAN  
電腦 → 交換器 → 本地伺服器。這條路徑不需經路由器或互聯網。
存取外部網頁  
電腦 → 交換器 → 路由器 → 互聯網 → 網頁伺服器。
無線接入  
手提電腦經 Wi-Fi 到 AP，再經網線到交換器。AP 關機會中斷這條無線路徑；若只拔掉 AP 到交換器的網線，Wi-Fi 仍可能顯示已連接，但到不了有線 LAN。正常的有線路徑仍可用。
TCP/IP 怎樣傳送資料
1. 拆分（TCP）  
發送端把資料拆成較小部分，並記錄次序。
2. 傳送（IP）  
封包帶有目的地 IP 地址，路由器根據地址轉送。
3. 檢查及重傳（TCP）  
若有部分遺失，須重傳並成功收到。
4. 重組（TCP）  
接收端收齊後，按原本次序重組資料。
例子  
抵達 1 → 3 → 2，重組 1 → 2 → 3。若欠缺第 2 部分，不能完整重組。編號只用於示意。
