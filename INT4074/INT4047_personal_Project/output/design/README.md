# Design artifacts

Updated Figma UI: https://www.figma.com/design/RZ7EY1OfYBUPXosK3EeBtr?node-id=14-6

- `ict-storyboard.html`: standalone viewer (serve this folder with the project server).
- `ict-storyboard-01.svg` to `03.svg`: vector flowcharts with English I/O labels.
- `ict-storyboard.drawio`: editable diagrams.net source. Open from Device.
- `../pdf/ict-storyboard-io.pdf`: three-page vector PDF.
- `../pdf/ict-design-links.pdf`: clickable artifact links and low-fidelity wireframes.
- `ict-ui-updated.svg`: local vector source for the 14-screen Figma board.

The Figma board uses Inter and Noto Sans HK because local SF Pro and Noto Sans TC were unavailable in the browser editor. Text and vector shapes remain editable. It is a grouped UI redraw rather than an auto-layout component library. Account/notification and automatic AI features remain prototypes or future work; the learning history is stored locally and can be exported.

Keep the design and pdf folders together for relative links. Local files are not public URLs; upload the storyboard PDF/source alongside the link sheet when submitting.
